68: ABSTRACT
69: 
70: 
71: 
72: The Autonomous Agricultural Grain Silo Aeration & Quality Optimization Hub is a software-based grain storage management system developed using Java Spring Boot and MySQL. The primary objective of the system is to help users monitor and manage grain storage conditions inside agricultural silos through a centralized web application.
73: The system maintains information about grain batches, silo capacity, temperature, humidity, moisture level, storage duration, and aeration status. Based on the recorded environmental and grain-quality parameters, the system provides recommendations regarding aeration and storage conditions. 
74: 
75: The application supports CRUD (Create, Read, Update, Delete) operations for managing silo and grain records. The backend is developed using Spring Boot, while Spring Data JPA and Hibernate are used for database interaction. MySQL is used to store silo, grain batch, environmental readings, and aeration records. The user interface can be developed using HTML, CSS, JavaScript, and Bootstrap. The system provides a dashboard for viewing silo conditions, identifying abnormal values, and maintaining historical records.
76: 
77: The proposed software model demonstrates how automated decision-support concepts can be applied to agricultural grain storage without requiring physical hardware. It provides a structured platform for monitoring grain quality and supporting timely aeration decisions.

148: CONTROLLER (ExpenseController.java)
149: 
150: 		package com.expense.controller;
151: 
152: import org.springframework.beans.factory.annotation.Autowired;
153: import org.springframework.stereotype.Controller;
154: import org.springframework.ui.Model;
155: import org.springframework.web.bind.annotation.*;
156: import com.expense.model.Expense;
157: import com.expense.service.ExpenseService;
158: import java.util.List;
159: 
160: @Controller
161: public class ExpenseController {
162: 
163:     @Autowired
164:     private ExpenseService expenseService;
165: 
166:     // List all expenses + total
167:     @GetMapping("/")
168:     public String listExpenses(Model model) {
169:         List<Expense> expenses = expenseService.findAll();
170:         double total = expenses.stream().mapToDouble(Expense::getPrice).sum();
171:         model.addAttribute("expenses", expenses);
172:         model.addAttribute("totalSum", total);
173:         return "expenses";
174:     }
175: 
176:     // Add new expense
177:     @PostMapping("/")
178:     public String addExpense(@ModelAttribute Expense expense) {
179:         expenseService.save(expense);
180:         return "redirect:/";
181:     }
182: 
183:     // Show update form
184:     @GetMapping("/update/{id}")
185:     public String showUpdateForm(@PathVariable Long id, Model model) {
186:         model.addAttribute("expense", expenseService.findById(id));
187:         return "update_expense";
188:     }
189: 
190:     // Update expense
191:     @PostMapping("/update/{id}")
192:     public String updateExpense(@PathVariable Long id, @ModelAttribute Expense expense) {
193:         expense.setId(id);
194:         expenseService.save(expense);
195:         return "redirect:/";
196:     }
197: 
198:     // Delete expense
199:     @GetMapping("/delete/{id}")
200:     public String deleteExpense(@PathVariable Long id) {
201:         expenseService.deleteById(id);
202:         return "redirect:/";
203:     }
204: }
